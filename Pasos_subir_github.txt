REGLA DE ORO AL INICIAR CUALQUIER PROYECTO (EL ORDEN IMPORTANTE)
-------------------------------------------------------------------
Hacer estos 3 pasos ANTES de hacer tu primer commit o push:

1. Crea el archivo ".gitignore" en la carpeta raiz de tu proyecto.
2. Abrelo y escribe estas lineas para bloquear todo de inmediato:
   .env
   venv/
   __pycache__/
3. Guarda el archivo. SOLO DESPUES de hacer esto, crea tu archivo ".env" 
   y pon tus contrasenas. Git lo volvera invisible desde el segundo uno.


COMO VERIFICAR EN LA TERMINAL ANTES DE SUBIR A GITHUB
-------------------------------------------------------------------
Antes de enviar tu codigo a internet, escribe siempre en tu Git Bash:

   git status

- SI TODO ESTA BIEN: El archivo ".env" NO DEBE aparecer listado por 
  ningun lado (ni en letras rojas ni verdes). Puedes subir con calma.
- SI APARECE EN LA LISTA: ¡Alto! No uses "git add .". Primero sacalo 
  usando este comando:
  
   git rm --cached .env


QUE HACER SI SE TE SUBE POR ACCIDENTE A GITHUB (EL SALVAVIDAS)
-------------------------------------------------------------------
Si por error el archivo llega a aparecer en la pagina web de GitHub, 
corre estos 3 comandos seguidos en tu terminal para borrarlo de la web:

1. git rm --cached .env
2. git commit -m "Remover archivo env de internet por seguridad"
3. git push origin main

* Nota: Despues de hacer esto, ve a tu .env local y cambia tu SECRET_KEY 
  y contrasenas por unas nuevas, porque las viejas ya quedaron grabadas 
  en el historial de internet.
